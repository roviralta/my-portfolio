# my-portfolio

Personal portfolio of Sergi Roviralta — Junior Software Engineer. Built with React 19 + Vite.

## Available Scripts

In the project directory, you can run:

### `npm run dev`

Runs the app in development mode. Open http://localhost:5173 to view it. The page reloads on edits.

### `npm run build`

Builds the app for production to the `dist` folder. It bundles React in production mode and optimizes the build for the best performance.

### `npm run preview`

Serves the `dist` build locally to preview the production output.

## Deploy

Deployed to Netlify (build command `npm run build`, publish dir `dist`). A `netlify.toml` is added during the deployment phase.
